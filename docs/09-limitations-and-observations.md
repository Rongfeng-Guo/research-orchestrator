# 模块说明与实现细节

本文档整理项目中的关键实现细节，便于阅读源码和理解各模块的行为边界。

## 1. 多智能体执行结构

项目包含以下核心角色:

- Planner
- Researcher
- Summarizer
- Red
- Blue

在执行层中:

- `search`
- `analyze`
- `verify`

三类子任务当前都由 `ResearcherAgent` 执行。

## 2. 工具调用深度

`ResearcherAgent` 的 prompt 对工具调用次数做了限制:

- 每个子任务最多 2 次工具调用

这一设计用于控制执行成本与运行稳定性。

## 3. Browser 模块

当前 `browser` 模块主要提供:

- HTTP 抓取
- HTML 正文提取

适合用于网页内容读取和文本抽取。

## 4. Code Sandbox 模块

`code_sandbox` 当前主要用于:

- 小规模表达式执行
- 简单 Python 逻辑运行

实现上采用受限执行方式。

## 5. 记忆层

`SharedMemoryStore` 提供以下能力:

- embedding 检索
- 去重
- 矛盾检测

这些能力用于组织中间证据和支持后续任务。

## 6. 压缩层

压缩模块包含:

- L1
- L2
- L3

三层策略，用于处理较长的上下文内容。

## 7. 对抗修复层

Red/Blue 模块负责:

- 识别报告中的问题
- 生成修复建议
- 执行文本级修复

这一层主要服务于报告质量提升。

## 8. Evolution 模块

`evolution/` 目录提供:

- 配置结构
- 训练循环骨架
- 数据收集与组织接口

可用于后续扩展训练闭环。

## 9. 文档与代码对应关系

阅读仓库时，可以重点关注以下对应关系:

- `README.md` 介绍项目整体结构和运行方式
- `docs/` 说明主流程、架构、配置与评测
- `src/` 提供核心实现
- `scripts/` 提供运行和实验入口

## 10. 推荐关注的增强方向

后续扩展时可以重点关注:

- 更深的工具调用循环
- 更真实的浏览能力
- 更强的工具选择策略
- 更严格的引用与事实核验
- 更深度接入压缩与记忆
- 更完整的训练闭环
