# Security Policy

## Reporting a Vulnerability

Do not open a public issue for suspected security vulnerabilities.

Report vulnerabilities privately to `rongfengguo.cs@gmail.com` with:

- A short description of the issue
- Affected files, scripts, or interfaces
- Reproduction steps or proof of concept
- Impact assessment if known

## Scope

Please report issues involving:

- Secret or credential exposure
- Unsafe file access or code execution paths
- SSRF, prompt injection, or retrieval abuse that crosses intended trust boundaries
- Supply-chain or packaging risks in release artifacts
- Data leakage through logs, reports, or stored memories

## Response Goals

- Initial acknowledgment: within 7 days
- Status update after triage: as soon as impact is understood
- Fix timeline: depends on severity, exploitability, and release scope

## Disclosure

Please allow reasonable time for investigation and remediation before public disclosure.
